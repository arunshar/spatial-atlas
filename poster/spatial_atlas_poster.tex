      \heil{Approach and why it will succeed} Four mechanisms instantiate
      compute-grounded reasoning (CGR) end to end.
      \par\vspace{0.18cm}
      \small
      \begin{itemize}\setlength{\itemsep}{0.08cm}
        \item \textbf{Typed scene evidence}: entities, estimated positions,
              relations, zones, and constraints.
        \item \textbf{Confidence-gated reflection}: one conditional refinement when
              self-graded confidence is below $0.6$.
        \item \textbf{Fail-closed execution}: generated code requires explicit opt-in
              and isolated-worker attestation.
        \item \textbf{Repair then score-gated refinement}: diagnose and patch failures
              using error and stdout traces. After successful execution, retain a
              refinement only when its parsed validation score improves.
      \end{itemize}
      \par\vspace{0.18cm}
      The spatial branch computes relations and facts. The ML branch analyzes tasks,
      generates and repairs pipelines, and compares pipeline-emitted validation scores.

  Standard from $0.6$ through $0.8$, and reflects or escalates below

  \begin{possection}{4.}{Evaluation}
    \fontsize{31}{33}\selectfont
    \heil{FieldWorkArena Handler} The v2 preprint describes a pipeline using
    Florence-2, GPT-4.1 vision, and bounding-box-centroid positions. The current
    repository instead obtains \apicode{position\_x} and
    \apicode{position\_y} from a Strong-model JSON extraction prompt.
    \par\vspace{0.12cm}
    \stp{1}\hspace{0.45em}Describe the image and extract entities and relations.\par
    \stp{2}\hspace{0.45em}Store a typed scene graph $G=(V,E)$.\par
    \stp{3}\hspace{0.45em}Compute pairwise distances and safety-rule violations.\par
    \stp{4}\hspace{0.45em}Pass a fact sheet to the final language model.\par
    \par\vspace{0.18cm}
    \heil{MLE-Bench Handler} Execution of generated code follows a fail-closed
    policy that requires explicit operator opt-in and isolated-worker
    attestation.
    \par\vspace{0.12cm}
    \stp{1}\hspace{0.45em}Analyze task type, metric, files, and constraints.\par
    \stp{2}\hspace{0.45em}Generate a strategy-specific Python pipeline.\par
    \stp{3}\hspace{0.45em}Run only inside the bounded worker after the gate.\par
    \stp{4}\hspace{0.45em}Diagnose, patch, and retry failures for at most 3 attempts.\par
    \stp{5}\hspace{0.45em}Parse \apicode{VALIDATION\_SCORE} after success.\par
    \stp{6}\hspace{0.45em}Refine at most twice and retain only a score improvement.\par
    \vspace{0.08cm}
    The rollback rule is explicit:
    \begin{equation}
      p_{t+1}=
      \begin{cases}
        p' & \mathrm{better}(s(p'),s(p_t))\\
        p_t & \text{otherwise}
      \end{cases}
    \end{equation}
    \vspace{-0.08cm}
    \begingroup
    \normalsize
    \heil{Prompted safeguards} The generated pipeline is instructed to check
    ID overlap, row fingerprints, temporal order, and byte-identical media.
    These checks are not independently enforced. Dummy fallback remains
    opt-in.\par
    \endgroup
  \end{possection}

  \begin{possection}{7.}{Integration Contributions}
    \possub{7.1}{Measured Geometry Bridge}
    The FieldWork handler can switch from the scene graph to a metric backend that
    invokes SpatialClaw perception primitives. Strict QSpatial mode fails closed
    rather than falling back.
    \par\vspace{0.16cm}
    \stp{1}\hspace{0.45em}Obtain object masks and a reconstructed point map.\par
    \stp{2}\hspace{0.45em}Erode masks and retain finite, confidence-qualified points.\par
    \stp{3}\hspace{0.45em}Build deterministic horizontal XZ voxel representatives.\par
    \stp{4}\hspace{0.45em}Compute symmetric directed nearest-neighbor 5th percentiles.\par
    \stp{5}\hspace{0.45em}Validate metric range, provenance, protocol contracts,
    and evidence hashes.\par
    \vspace{0.10cm}
    \begin{align}
      d_{A\rightarrow B}
        &= Q_{.05}\!\left(
          \left\{\min_{b\in B}\lVert a-b\rVert_{XZ}:a\in A\right\}
        \right)\\
      \hat d(A,B) &= \min(d_{A\rightarrow B},d_{B\rightarrow A})
    \end{align}
    \vspace{-0.20cm}
    {\color{ncmuted}\normalsize SpatialClaw supplies the perception primitives.
    Erosion, voxelization, the surface-gap estimator, strict validation, and
    the Atlas scene bridge are local Spatial Atlas work.}
    \par\vspace{0.26cm}

    \possub{7.2}{Shared Action Contracts}
    The integration contract defines four requirements:
    \begin{itemize}\setlength{\itemsep}{2pt}
      \item \textbf{Kernel-visible state}: expose entities, values, confidence,
            units, and provenance.
      \item \textbf{Stateful contract}: inspect, compose, recompute, and revise
            evidence per observation.
      \item \textbf{Evidence-use journal}: record facts and tool outputs used
            by each answer.
      \item \textbf{Verifier contract}: count only answers backed by fresh,
            valid, attested evidence.
    \end{itemize}
    \par\vspace{0.20cm}
    \begin{takeaway}
      {\ttfamily\footnotesize\bfseries\color{ncgreendark}\MakeUppercase{Take-away}}\par
      \vspace{0.12cm}
      {\color{ncink}\normalsize Spatial Atlas makes evidence explicit and
      verifiable. SpatialClaw adds metric perception and a stateful action loop
      so spatial answers can be recomputed, revised, and traced to evidence.}
    \end{takeaway}
  \end{possection}
